# Chrome Web Store assets

This directory contains screenshots, promotional artwork, and source files used for the NodeSnip Chrome Web Store listing. These files are public repository assets and are not included in `NodeSnip.zip`.

Before committing an uploadable PNG, inspect its EXIF, XMP, and color-profile metadata and remove any contributor-identifying or device-specific fields. Preserve the intended appearance and verify the final dimensions after sanitizing the file.
